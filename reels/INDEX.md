# Reels index

Everything in `reels/NNN_*.mp4` is generated by the code in `reels/src` (`python3 build.py <batch> --out ..`). 1080x1920, 30fps, with synthesized music + sound effects (no samples, nothing to license).

Captions below are suggested post text. Cultural reels are written as affectionate observational comedy about food, family, hospitality, cars and habits.
